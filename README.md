# MAYBE — портфолио Ильи Зубкова

Статический сайт на HTML, CSS и JavaScript. Публикуется через GitHub Pages при обновлении ветки `main`.

## Страницы

- `index.html` — главная: позиционирование, слайдшоу проектов, подход, услуги, вопросы и контакт.
- `work.html` — все проекты с фильтрами.
- `project.html?slug=...` — кейс проекта.
- `contact.html` — контакты и информация для первого письма.

«Обо мне» открывается в боковом окне с любой страницы. Старый адрес `about.html` перенаправляет на главную с открытым окном.

## Где менять содержание

- `assets/projects.js` — названия, описания, годы, роли, обложки и галереи проектов на русском и английском.
- `assets/site.js` — навигация, фильтры, полноэкранное мобильное меню, окно «Обо мне» и вывод кейсов.
- `assets/site.css` — оформление и адаптивная сетка.
- `assets/page-entry.js` — подготовка страницы и переходы к секциям без рывков.
- HTML-файлы — тексты остальных страниц. Для перевода у элементов используются атрибуты `data-ru` и `data-en`.
- `assets/maybe-logo.svg` — логотип; `assets/about-photo.png` — портрет.

Для просмотра локально откройте `index.html` в браузере. Если на компьютере установлен Python, можно запустить из корня проекта `python -m http.server 4173` и открыть `http://127.0.0.1:4173/`. Сборка и установка зависимостей не требуются.

Сайт использует композиционную архитектуру [MONOLOG](https://bymonolog.com/) как референс. Его тексты, логотип, фотографии клиентов и заявленные результаты в проект не переносились.

## Текстовая структура AXONIC

Кейс открывается по `project.html?slug=axonic`. Для AXONIC включён `layout: "chapters"`: первый экран с крупным названием, описанием и данными проекта, затем обложка с фиксированными пропорциями 16:9 на всех устройствах, с небольшими полями и скруглениями, далее пять разделов с текстом слева и медиа в рамке 16:9 справа. Видеообложка Kinescope подключена через `coverEmbed`; для статичного изображения предусмотрено поле `cover`. Встроенное видео служит фоном и не перехватывает колесо мыши или касания: прокруткой управляет страница. `textSide: "right"` меняет колонки текстовых разделов местами. На компьютере экраны перелистываются колесом мыши или клавишами, длинные разделы имеют дополнительную остановку для чтения. На узких экранах текст и заглушка располагаются друг под другом с обычной прокруткой.

В `assets/projects.js` блок «О проекте» находится в `caseIntro` и показывается на первом экране под названием проекта. Первый пункт после основной обложки — «Всё начинается с импульса». Его первый кадр — видео семантики знака, затем два изображения. Массив `caseBlocks` содержит следующие части: концепция знака → графические константы, типографика, цвет и сетка → инструмент генеративной графики → носители и коммуникации → AI-пайплайн. Тексты адаптированы из авторского [кейса на Dprofile](https://dprofile.ru/case/194897/axonic-vizualnaia-sistema-neirotexnologiceskogo-brenda), включая текстовые слайды. Статус проекта — концепт.

В разделе «Всё начинается с импульса» добавлено изображение `assets/projects/axonic/axonic-impulse.png`. Изображения разделов задаются через `media: { src, alt }` или массив таких объектов у блока в `caseBlocks`. В первом разделе три кадра: видео семантики знака, логотип и модульная сетка знака. Для видео в массиве `media` используется `embed` вместо `src`. Поля `width` и `height` хранят исходные размеры; все рамки имеют пропорции 16:9, изображения и видео заполняют общую рамку со скруглениями и совпадающими боковыми краями. Изображения других пропорций обрезаются по центру через `object-fit: cover`. При перелистывании кадров текст слева закреплён до следующего раздела. На узких экранах изображения идут друг под другом с обычной прокруткой. Пока материал не задан, `renderProjectChapters()` показывает заглушку 16:9. Остальные кейсы используют общий шаблон с `cover` и `media`.

На главной AXONIC идёт первым в слайдшоу и использует видео из `coverEmbed`. Видео не перехватывает клики по ссылке на кейс и колесо мыши; при уходе со слайда или из видимой области iframe отключается.

После AXONIC ссылка «Следующий проект» ведёт на Redsoft (`nextProject: "redsoft"`). Пока материалы не добавлены, `pending: true` показывает страницу «Кейс готовится» и скрывает проект из общего каталога.

На десктопах ширина рамки дополнительно ограничена доступной высотой окна с учётом верхнего отступа и нижнего поля. Каждый кадр занимает один экран; дополнительные остановки последовательностей исключены. Для длинного текста AI-пайплайна сохранена остановка для дочитывания. Типографика левой колонки совпадает с главной: Inter, заголовок `--intro-size` (21 px на Full HD и 2K), текст `--rail-body-size` (16 px).
